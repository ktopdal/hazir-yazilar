Düzenleme anahtarı

Bu sayfadan ekleme ve düzenleme yapmak için her cihaza bir kez GitHub anahtarı girilir. Anahtar yalnızca bu cihazın tarayıcısında saklanır.

  1. github.com/settings/personal-access-tokens/new sayfasını aç.
  2. Token name: Hazir Yazilar. Expiration: istediğin süre.
  3. Repository access → Only select repositories → hazir-yazilar.
  4. Permissions → Contents → Read and write.
  5. Generate token'a bas, çıkan anahtarı kopyala ve aşağıya yapıştır.
